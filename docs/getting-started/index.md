# Getting Started with SeaBlock

Welcome to SeaBlock! This guide will help you get started with one of the most challenging and rewarding mods for Factorio.

## What is SeaBlock?

SeaBlock is a total conversion mod that completely changes how Factorio works. Instead of starting on a continent with rich ore patches, you begin on a tiny island in the middle of an infinite ocean. Your only resources are:

- **Water** - Infinite source of H₂O
- **Air** - Source of nitrogen and oxygen
- **Sunlight** - For solar power and algae farming
- **Seafloor** - Limited landfill for expansion

## Key Concepts

### Resource Generation

Unlike vanilla Factorio, you can't mine ore directly. Instead, you must:

1. **Extract from water** - Use electrolysers to get hydrogen, oxygen, and trace metals
2. **Grow algae** - Convert water and CO₂ into biomass
3. **Process biomass** - Create wood, oil, and other organic materials
4. **Refine metals** - Use complex chemical processes to extract pure metals

### Power Generation

Early game power comes from:

- **Steam engines** - Burn wood or charcoal
- **Solar panels** - Convert sunlight to electricity
- **Wind turbines** - Generate power from wind (if available)

### Space Management

Land is precious! You'll need to:

- **Reclaim land** - Use landfill to expand your island
- **Build vertically** - Use multi-story designsugh
- **Optimize layouts** - Every tile counts

## Installation

### Prerequisites

- Factorio 1.1.x (latest stable)
- Factorio Mod Portal access

### Required Mods

The SeaBlock mod pack includes:

1. **Sea Block** - Core mod
2. **Angel's Mods** - Processing chains and buildings
3. **Bob's Mods** - Additional content and complexity
4. **Additional Mods** - Various supporting mods

### Installation Steps

1. **Download the mod pack** from the [Factorio Mod Portal](https://mods.factorio.com/mod/SeaBlock)
2. **Enable all mods** in the mod manager
3. **Start a new game** with the SeaBlock scenario
4. **Choose your difficulty** - SeaBlock has multiple difficulty levels

## Your First Steps

### 1. Initial Setup

When you start, you'll have:

- A small island with basic resources
- A few starting buildings
- Some initial power generation

### 2. Basic Resource Loop

Your first goal is to establish a basic resource loop:

```
Water → Electrolyser → Hydrogen + Oxygen
Water + CO₂ → Algae Farm → Algae
Algae → Algae Processing → Cellulose Fiber
Cellulose Fiber → Wood Pellets → Wood
Wood → Charcoal → Power
```

### 3. Power Management

- **Monitor power consumption** - Don't let your base run out of power
- **Build backup power** - Have multiple power sources
- **Use efficiency modules** - Reduce power consumption

### 4. Land Expansion

- **Plan your expansion** - Think about where you'll need space
- **Use landfill efficiently** - Don't waste it on unnecessary areas
- **Consider future needs** - Leave room for larger buildings

## Common Pitfalls

### Power Death Spiral

- **Problem**: Running out of power stops production, which stops power generation
- **Solution**: Always have backup power sources and monitor consumption

### Resource Bottlenecks

- **Problem**: One resource running out stops everything
- **Solution**: Build buffer chests and monitor resource flows

### Space Constraints

- **Problem**: Running out of space for new buildings
- **Solution**: Plan ahead and use compact designs
