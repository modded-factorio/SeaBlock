# WYSIWYG Editor

Edit wiki content with our browser-based editor that provides a true "What You See Is What You Get" experience. The editor is available on every page as a floating widget.

## Features

- ✅ **Real-time preview** - See changes instantly as you type
- ✅ **VitePress rendering** - Uses the same renderer as the live site
- ✅ **Copy to GitHub** - Easy publishing workflow
- ✅ **Dark/Light themes** - Choose your preferred theme
- ✅ **Fullscreen preview** - Test navigation and full-page rendering
- ✅ **Markdown shortcuts** - Common keyboard shortcuts for faster editing
- ✅ **Global access** - Available on every page via floating button

## Getting Started

1. **Open the editor** - Click the floating ✏️ button in the bottom-right corner of any page, or press `Ctrl+E`
2. **Edit content** - Type markdown in the left pane
3. **Preview changes** - See live preview in the right pane
4. **Copy to GitHub** - When ready, copy your content to GitHub for publishing

::: tip Quick Access

- **Keyboard shortcut**: Press `Ctrl+E` (or `Cmd+E` on Mac) to open the editor from any page
- **Floating button**: Look for the ✏️ button in the bottom-right corner
- **Copy shortcut**: Press `Ctrl+S` (or `Cmd+S` on Mac) while the editor is open to copy to GitHub
  :::

## How It Works

### True WYSIWYG Experience

Unlike traditional markdown editors that show a generic preview, our editor uses the actual VitePress renderer. This means:

- **Exact styling** - What you see is exactly what visitors will see
- **Component rendering** - Custom Vue components render correctly
- **Theme consistency** - Matches the live site's theme perfectly
- **No surprises** - No differences between preview and production

### Browser-Based Architecture

The editor runs entirely in your browser:

- **No server required** - Works offline after initial load
- **Fast performance** - Instant preview updates
- **Privacy focused** - Your content never leaves your browser
- **Cross-platform** - Works on any device with a modern browser

### GitHub Integration

Seamless publishing workflow:

1. **Edit locally** - Use the WYSIWYG editor to create content
2. **Copy to GitHub** - One-click export to GitHub editor
3. **Submit PR** - Standard GitHub pull request workflow
4. **Auto-deploy** - Changes automatically deploy to the live site

## Editor Features

### Split-Pane Interface

- **Left pane** - Markdown source editor with syntax highlighting
- **Right pane** - Live preview using VitePress renderer
- **Resizable** - Drag the splitter to adjust pane sizes
- **Synchronized** - Both panes stay in sync automatically

### Markdown Shortcuts

Common keyboard shortcuts for faster editing:

- `Ctrl/Cmd + B` - Bold text
- `Ctrl/Cmd + I` - Italic text
- `Ctrl/Cmd + S` - Copy to GitHub
- `Tab` - Indent list items
- `Shift + Tab` - Outdent list items

### Theme Support

- **Light theme** - Clean, bright interface for daytime editing
- **Dark theme** - Easy on the eyes for nighttime editing
- **Auto-sync** - Preview theme matches editor theme
- **Persistent** - Theme preference is remembered

### Fullscreen Preview

Test your content in a full-page view:

- **Navigation testing** - See how links and navigation work
- **Mobile preview** - Test responsive design
- **Print preview** - See how content looks when printed
- **Full context** - View content in its complete layout

## Content Guidelines

### Markdown Best Practices

- **Use proper headings** - H1 for page titles, H2 for sections, etc.
- **Include front matter** - Add metadata at the top of files
- **Use code blocks** - Specify language for syntax highlighting
- **Add alt text** - Include descriptions for images
- **Link appropriately** - Use relative links for internal pages

### VitePress Features

Take advantage of VitePress-specific features:

- **Custom containers** - Use `::: tip`, `::: warning`, etc.
- **Code groups** - Group related code examples
- **Badges** - Add status badges to content
- **Custom components** - Use Vue components in markdown

## Troubleshooting

### Common Issues

**Preview not updating?**

- Check for markdown syntax errors
- Refresh the page if needed
- Ensure all brackets and quotes are properly closed

**Copy to GitHub not working?**

- Check your browser's popup blocker settings
- Ensure you have write access to the repository
- Try copying manually if the button doesn't work

**Styling looks different?**

- Clear your browser cache
- Check if you're using the latest version
- Report styling issues on GitHub
